### LaTeX Templates
In this repository, I'll upload some of my old LaTeX templates, including templates for
- books,
- home assignments,
- lab reports,
- resumes,
  
and other things. Here, you will also find old figures I created using TikZ. Sometimes, you can also find my templates on Overleaf. Here's one [example](https://www.overleaf.com/latex/templates/basic-homework-template/vrpzjpnpscbx).

Please let me know if you find any issues. I welcome any suggestions!
